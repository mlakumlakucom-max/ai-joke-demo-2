# The Joke About the Demo

A one-line joke about working beside an AI coding agent — written for developers who have watched a live demo crash and seen their agent "fix" it in the most agent way possible.

The program writes the joke to `entry.txt` (UTF-8, one line, 1–280 Unicode code points).

## Run it

```sh
node main.ts
```

This writes `out/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to choose a different output directory:

```sh
MAKEFUN_OUTPUT_DIR=./my-out node main.ts
```

Requires Node 22 or later. Standard library only, no dependencies, no network.
